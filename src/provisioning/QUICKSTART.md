# Quick Start Guide - CrowdCount Provisioning

## For Developers (Testing)

### 1. Install on Raspberry Pi

```bash
# SSH into your Pi
ssh pi@raspberrypi.local

# Clone/copy the code
cd ~/
git clone <your-repo> crowdcount-counter
cd crowdcount-counter/src/provisioning

# Run setup
./setup_provisioning.sh
```

### 2. Create Test Device Identity

```bash
# Create identity file
sudo nano /boot/device-identity.conf
```

Paste:
```ini
[DEFAULT]
DEVICE_ID=CC-DEV-001
DEVICE_SECRET=test-secret-123
MANUFACTURING_DATE=2024-01-01
MODEL=counter-v2
```

### 3. Test Provisioning

```bash
# Run manually
python3 provision_manager.py

# You should see:
# 🔵 Starting Bluetooth provisioning server
#    Device name: CrowdCount-CC-DEV-001
# ✓ Bluetooth server started
#    Waiting for mobile app to connect...
```

### 4. Generate Test QR Code

```bash
# Install qrencode
sudo apt install qrencode

# Generate QR code
qrencode -s 6 -o test-qr.png "crowdcount://provision?id=CC-DEV-001&secret=test-secret-123"

# Display QR code (or transfer to phone to test scanning)
display test-qr.png
```

## For Manufacturers

### 1. Prepare Base Image

```bash
# Flash Raspberry Pi OS
# Install software
cd ~/crowdcount-counter/src/provisioning
./setup_provisioning.sh
sudo ./install_services.sh

# Create base image
sudo dd if=/dev/mmcblk0 of=crowdcount-base.img bs=4M status=progress
gzip crowdcount-base.img
```

### 2. Customize Each Device

```bash
# Flash base image
sudo dd if=crowdcount-base.img.gz of=/dev/sdX bs=4M status=progress

# Mount boot partition
sudo mount /dev/sdX1 /media/boot

# Customize (device #1)
cd ~/crowdcount-counter/manufacturing
./customize_sd_card.sh 1 /media/boot

# Unmount
sudo umount /media/boot
```

### 3. Print QR Codes

```bash
# QR codes are in manufacturing/qr_codes/
cd manufacturing/qr_codes

# Print to label printer
for qr in *.png; do
    lpr -P LabelPrinter "$qr"
done
```

### 4. Assembly & QC

For each device:

- [ ] Apply QR code sticker to case
- [ ] Power on and verify Bluetooth advertising
- [ ] Test provision with test WiFi
- [ ] Reset provisioning state
- [ ] Package and ship

## For End Users (Customer Experience)

### 1. Unbox Device

- Remove from packaging
- Locate QR code on device
- Plug in power

- Open CrowdCount app
- Tap "Add Device"
- Scan QR code on device
- Enter WiFi credentials
- Tap "Connect"
- Wait for setup to complete

### 3. Start Using

- Device appears in app
- View live stream

## Troubleshooting

### Provisioning Not Starting

```bash
# Check service
sudo systemctl status crowdcount-provision.service

# Check if already provisioned
ls -la /boot/provisioned

# Force re-provision
sudo rm /boot/provisioned
sudo reboot
```

### Bluetooth Not Visible

```bash
# Check Bluetooth
sudo systemctl status bluetooth

# Check logs
sudo journalctl -u crowdcount-provision.service -f

# Test manually
sudo bluetoothctl
power on
scan on
```

### WiFi Won't Connect

```bash
# Check NetworkManager
sudo systemctl status NetworkManager

# Try manual connection
sudo nmcli dev wifi connect "YourNetwork" password "YourPassword"
```

## File Structure

```
crowdcount-counter/
├── src/
│   ├── provisioning/
│   │   ├── device_identity.py          # Read device ID/secret
│   │   ├── bluetooth_server.py         # BLE GATT server
│   │   ├── network_setup.py            # WiFi/Tailscale config
│   │   ├── provision_manager.py        # Main entry point
│   │   ├── setup_provisioning.sh       # Install script
│   │   ├── install_services.sh         # Install systemd services
│   │   ├── *.service                   # Systemd service files
│   │   └── requirements.txt            # Python deps
│   └── counter-stream/
│       ├── stream_to_mediamtx.py       # Streaming (unchanged)
│       └── device-info.conf            # Auto-generated by provisioning
├── boot/
│   └── device-identity.conf.template   # Template for manufacturing
└── manufacturing/
    ├── customize_sd_card.sh            # Customize SD cards
    ├── manufacturing_log.csv           # Production log
    └── qr_codes/                       # Generated QR codes
```
